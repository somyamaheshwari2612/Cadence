Project Architecture & Approach
Exposure Router: A deterministic scheduling engine that evaluates user task constraints against Open-Meteo CAMS air quality and hourly weather forecasts, using Gemini 3.5 Flash-Lite to translate mathematical slot selections into readable reasoning.

Verified Eco-Streak: A gamified daily action system generating context-aware environmental tasks. It relies on a native mobile camera capture and Gemini Flash Vision to validate object presence, hand gestures, and anti-spoofing screen checks.

Backend Blueprint (Python/Flask)
app.py: Initializes Flask and CORS, registers the /api/schedule and /api/verify-task REST endpoints, and routes incoming JSON payloads to the corresponding service modules.

services/env_data.py: Manages the decoupled Open-Meteo HTTP requests, validates time alignments, handles missing pm2_5_ug_m3 or temperature values, and strictly formats the grid coordinate metadata.

services/scheduler.py: Houses the core mathematical rules. It drops time slots breaching defined thresholds, scores valid slots by combining apparent temperature and U.S. AQI risk, and outputs a deterministic fact string.

services/llm_engine.py: Constructs strict JSON schemas and system prompts for Google AI Studio, handling the explainer text generation and the multipart image payload for the gesture/scene check.

Frontend Blueprint (Next.js 14 App Router)
src/app/page.tsx: Acts as the primary state container, structuring the dark-themed UI into a central routing dashboard and an unobtrusive side panel for the environmental streak.

src/components/RouterForm.tsx: Captures user intents, managing state for task names, estimated durations, and safety tolerances before dispatching the payload to the Flask API.

src/components/Timeline.tsx: Iterates over the backend schedule array, displaying time slots, environmental metrics, and the LLM-generated explanation in frosted-glass interface cards.

src/components/EcoStreak.tsx: Triggers the device's rear camera using <input type="file" capture="environment" />, manages the image-to-Base64 conversion, and renders the soft-reject UI state if the vision model detects a screen or misses the gesture.
