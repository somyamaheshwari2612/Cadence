# Cadence

Cadence is a modern exposure-routing application that helps users safely plan their daily activities (like exercise, commutes, and outdoor tasks) around hyper-local air quality index (AQI) forecasts and environmental data.

## Features

- **Hyper-Local Forecasting**: Leverages Open-Meteo's hourly Air Quality and Weather APIs.
- **Smart Scheduling**: Recommends the safest timeslots based on user-defined activity duration and health preferences.
- **National Context Dashboard**: Real-time view of air quality across 100 Indian cities and major hubs.
- **Eco-Streak & Vision Verification**: Encourages consistent healthy choices by allowing users to verify their safe activities via image upload and Gemini Flash Vision analysis.
- **Modern UI**: Next.js & Tailwind CSS frontend built with sleek, dark-mode styling and fluid animations.

## Tech Stack

**Backend**
- Python 3.x
- Flask / FastAPI
- Google Gemini SDK
- Open-Meteo API Integration

**Frontend**
- Next.js (React)
- Tailwind CSS

## API Attribution
Air quality and weather data provided by [Open-Meteo](https://open-meteo.com/).

## Disclaimer
The activity recommendations are general informational guidance based on air quality metrics and are not a substitute for personalized medical advice.
